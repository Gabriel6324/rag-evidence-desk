知据 Evidence Desk 1.2.2

【这是什么】
这是本机资料问答工作台。导入讲义、制度或项目说明，再用自然语言提问，点击回答里的引用核对原文。软件按导入资料查找，不会自动搜索互联网。首次准备了 5 份虚构资料，没有 Key 也能体验。

【打开】
完整解压 Windows 运行包，双击 ZhiJuEvidenceDesk.exe。工作台就绪后自动打开浏览器；保留启动窗口即可持续使用，关闭它会停止服务。不要只移动 EXE，旁边的目录需要保留。
也可以进入工作台，在“接口设置”中配置模型；两处入口的设置完全一致。

【先这样试】
1. 点击示例问题，看回答。
2. 点击 E1 等引用，再点击“查看原文”核对出处。
3. 在“资料库”导入自己的 PDF、DOCX、TXT 或 Markdown；默认自动建立索引。
4. 索引就绪后回到“资料问答”，选择全部资料或指定文件再提问。
5. 同一会话可以继续追问，记录在本机保存。新问题组点击“新会话”。
单文件不超过 10 MB；扫描 PDF 先 OCR。改变资料、切分参数或向量模型后重建索引。

【三个模型】
对话模型：读问题和证据，组织回答。使用真实 AI 回答时配置。
向量模型：把文字转为向量，按含义查找资料。可选，默认用本机词面特征。
重排模型：给候选证据重新排序。可选，未配时保留原排序。
从对应服务商的 API 控制台获取基础地址、模型 ID 和调用密钥；三类可以来自不同服务商。字段和操作旁的“？”有独立的定义、获取与填写步骤。

API Key 是调用凭证；显示只显示本次输入，留空保留原 Key，勾选清除需要保存。建议先测试后保存。Windows 保存后自动重启，资料和会话保留。无需真实模型时点击“切回离线演示”。
测试只发送固定短文本。真实索引、问答和重排会发送必要资料片段，平台可能计费；费用与额度以平台账户为准。

【RAG 和 Agent】
RAG 做一轮检索后回答；Agent 分步检索与查阅原文。默认 Agent 是规则演示，真实模型决定步骤需支持工具调用的对话模型。运行详情显示步骤、耗时、缓存和模型实际返回的 token 用量。

【评测页面】
日常查资料可以跳过。对照评测比较 12 组参数；优化前后对比比较 4 组策略，两者离线运行。真实模型评测比较 2 组，必须确认 API 调用及计费。每组 18 道虚构资料题，评测不改动日常资料库。
完整证据率表示必要原文是否全部找齐；引文匹配率表示摘录是否存在于原文，均不能当作真实业务回答正确率。每个按钮和指标旁的“？”解释用途与操作。

每轮结果独立保存，新记录位于旧记录上方；点击标题展开旧结果，分别下载对应的 JSON、CSV、Markdown 报告。刷新或重启后记录仍保留，旧版完整报告会恢复。新一轮失败只影响本轮，可打开该轮引导；重启中断的任务不会自动重跑。
禁用按钮显示不可操作光标，正在执行的按钮显示等待光标。删除会话不可用时，悬停查看原因。

【遇到失败】
提醒显示失败操作和阶段。点击右侧“查看原因与解决方法”，按这次错误对应的步骤处理，再回原按钮重试。文件权限、文件占用、模型 Key、额度、网络、题库等分别有引导；原因不确定时会明确说明。
提醒会跨页面保留；点 X 可关闭同一条，新失败仍会显示。详情可复制或导出，诊断遮挡密钥。重新运行真实模型任务可能产生新的 API 费用。

【MCP 与数据】
接口设置显示当前 MCP 地址，供同一台电脑上支持 Streamable HTTP 的 AI 客户端连接；保持知据运行。提供查询和原文查看，不提供修改资料或读取 Key 的工具。
Windows 配置和资料默认在 %LOCALAPPDATA%\ZhiJuEvidenceDesk。升级时解压到新目录，原有数据会保留；迁移和备份前关闭服务。不要同时运行两个访问同一索引的实例。
Key 保存在本机文本配置中，不向页面回填；按本机文件权限保护。离线模式在本机处理，接入 API 后服务商会收到相应调用内容。

【当前范围】
本机单用户应用。引用校验检查出处与逐字摘录，不能证明逻辑结论正确；重要结果请核对原文。提示注入规则覆盖有限。付费模型质量与真实 Windows 运行需要相应环境验证。
