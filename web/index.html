使用说明

知据是做什么的？

这是一个在电脑上运行的资料问答工具。把讲义、工作说明等文档放进去，再像聊天一样提问，软件查找相关原文、整理回答，并标出出处。

例如：上传报销规则，问“住宿上限是多少、需要什么证明？”，再点击引用核对。它按导入资料回答，不会自动搜索互联网。没有 Key 时在本机查找和摘录；接入对话模型后可让模型组织回答与推理。

先这样用

  1. 打开：解压整个运行包，双击 EXE。工作台自动打开，保留启动窗口。
  2. 先体验：点击示例问题，再点击回答里的 E1 等引用，看右侧证据与原文。
  3. 用自己的资料：进入“资料库”，拖入 PDF、Word、TXT 或 Markdown。默认自动索引，完成后回到“资料问答”。
  4. 连接模型：点击右上角“模型设置”，在表单中勾选接口、填写地址、Key 和模型名，测试后“保存并应用”。更换向量模型时重建索引。
  5. 继续追问：在同一会话里继续提问；点击“新会话”可以开始另一组问题。回答与运行详情均可导出。

常见问题

没有 API Key，能不能用？

可以。离线演示能检索并摘录原文，还能展示规则工具流程。要理解改写后的意思、进行推理和由模型决定工具步骤，需要接入相应的真实模型。

三个接口必须全部填吗？

不用。先连接对话模型即可。向量模型用于语义检索，重排模型用于候选证据排序；两者都可以稍后开启，也可以来自不同服务商。

地址和模型名应该填什么？

填写服务商提供的兼容 API 基础地址，通常以 /v1 结尾，不要填完整的 /chat/completions 或 /embeddings 地址。模型名使用控制台中的模型 ID，也可点击“获取可用模型”后选择对应类型。

测试报 401、403、404 或 429 怎么办？

401 检查 Key；403 检查接口权限；404 检查基础地址和模型名；429 检查 API 余额、额度和请求频率。测试结果不会覆盖当前设置，可以修改后重试。

为什么提示“需要重建索引”？

资料或向量模型发生了变化。进入“资料库”，点击“重建向量索引”。索引记录了旧的资料与向量空间，必须更新后再提问。

回答“资料不足”，是软件坏了吗？

通常不是。资料可能没有答案、范围选错、必要条件缺失，或阈值过滤了证据。先查看右侧证据，再补充资料或改写问题；不要把只提到同一个人或主题的段落当作答案。

RAG 和 Agent 有什么区别？

RAG 做一轮检索后回答。Agent 会分步骤检索与查阅原文，适合跨资料问题。离线 Agent 使用规则演示；接入支持工具调用的对话模型后，才由模型决定这些步骤。

能读扫描 PDF、图片或者超大文件吗？

当前每份文件不超过 10 MB。支持有文字层的 PDF、DOCX、TXT 和 Markdown；扫描件或图片需要先转成可提取文字的文件。无法识别时会提示，不会假装读取成功。

有引用，就代表回答一定正确吗？

不一定。系统检查引用编号和引文是否出现在原文中，但结论仍可能缺少条件或理解错误。重要结论请打开原文核对；评测中的证据召回率也不是业务回答准确率。

我的资料、Key 和会话会发给谁？

离线模式全部在本机处理。连接 API 后，向量接口收到待向量化文字，重排接口收到问题与候选片段，对话接口收到问题和必要证据。Key 保存在本机，不在页面回显；调用密钥不向网页回填已保存的内容。

怎么验证效果？评测会收费吗？

“运行对照评测”离线比较 12 组参数；“运行优化前后对比”离线比较四组策略。两者使用内置虚构资料，不调用外部模型。真实模型评测需勾选计费确认，比较 2 组 × 18 题，并显示模型模式、完整证据率和拒答率。两者均不改动你自己的资料库。

关闭页面之后，还能找回会话吗？

可以。会话保存在本机，重新打开后从会话列表选择。Windows 数据默认放在当前用户的应用数据目录，重新解压新版不会覆盖它。关闭启动窗口才会停止本机服务。

遇到失败如何处理？

提醒会跨页面保留。点击右侧“查看原因与解决方法”，查看这次操作的失败步骤和对应处理方法；处理后回原按钮重试。点击“×”可收起提醒，切换页面不会重新弹出同一条。不能确定原因时，复制或导出错误详情用于排查。
