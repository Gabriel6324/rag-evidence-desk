启用语义检索与生成

  1. 将项目根目录的 .env.example 复制为 .env。
  2. 填写 Embedding 与 LLM 的地址、模型名和 API Key。两者可以来自不同服务商。
  3. 设定 RAG_EMBEDDING_MODE=api 和 RAG_ANSWER_MODE=llm。
  4. 重启服务，然后在资料库中重建索引。

使用兼容 /embeddings 与 /chat/completions 的接口。配置后，资料片段和问题会发送至所填服务。费用由服务商计收。

这套系统如何工作

资料提取页码 / 章节→切分与向量化Embeddings→混合检索Qdrant + BM25→回答与核验原文引用

系统目前面向本机单用户使用。边界说明、评测方法和代码结构见压缩包中的 README 与 docs。
